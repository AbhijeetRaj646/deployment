# Defence Coaching Institute Website

A modern and professional website for a Defence Coaching Institute built with React + Vite.

## Features

- **Responsive Design**: Mobile-first approach with clean navy blue, white, and army green theme
- **Complete Sections**: Hero, About Us, Courses, Success Stories, Faculty, Notices, Contact
- **Interactive Elements**: 
  - Learn More buttons with expandable course details
  - Testimonial carousel with auto-rotation
  - Faculty profile modals
  - Contact form with validation
  - Tabbed notices section
- **SEO Optimized**: Meta tags, structured data, sitemap, robots.txt
- **Modern Tech Stack**: React 18, Vite 5, CSS3 with custom properties
- **Automated Deployment**: GitHub Actions workflow for GitHub Pages

## Course Coverage

- **NDA (National Defence Academy)**: Complete preparation program
- **CDS (Combined Defence Services)**: Expert coaching for all streams
- **AFCAT (Air Force Common Admission Test)**: Specialized Air Force preparation
- **CAPF (Central Armed Police Forces)**: Comprehensive paramilitary training
- **SSB Interview Preparation**: Personality development and interview skills

## Live Website

The website is automatically deployed to GitHub Pages at: `https://abhijeetraj646.github.io/defence-coaching-site/`
